# Week 3 – Password Security Lab

A hands-on cybersecurity lab focused on understanding PDF password protection, hash extraction, and password security tools using Kali Linux and NetworkWalks tools.

## Project Overview

During Week 3 of my cybersecurity training, I completed two practical modules involving password-protected PDF files and learned how different tools support password security testing in an authorized lab environment.

## Module 1 – John the Ripper (JTR)

**Tools Used:**
- Kali Linux
- John the Ripper
- PDF2John
- RockYou Wordlist

**Tasks Performed:**
- Checked John the Ripper installation.
- Identified the password-protected PDF file.
- Extracted the PDF hash using PDF2John.
- Prepared and verified the hash file.
- Worked through the password recovery lab.
- Verified the result by opening the protected PDF.

## Module 2 – NetworkWalks Tools

**Tools Used:**
- NetworkWalks Hash Calculator
- NetworkWalks Password Cracker
- Web Browser

Tasks Performed:
- Generated the PDF hash using the Hash Calculator.
- Uploaded the hash to the NetworkWalks Password Cracker.
- Completed the assigned lab exercise.
- Verified the result by opening the protected PDF.
